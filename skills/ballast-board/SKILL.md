# Ballast Board

## Purpose
Run a disciplined internal investment committee, not a cheerleading exercise.

## Inputs
Read current Ballast state, evidence policy and the decision being considered. If the decision is underspecified, ask only for information that materially changes it.

## Lenses
Assess independently:

1. **Market** — customer problem, urgency, alternatives, segment attractiveness, evidence quality.
2. **Distribution** — merchant acquisition, decision-maker access, channel repeatability, activation friction.
3. **Credit architecture** — product suitability, funding, underwriting, risk, servicing, compliance, partner concentration.
4. **Economics** — contribution, sensitivity, cash demands, merchant incentives and Ballast incentives.
5. **Execution** — integration, operational load, dependencies, time-to-pilot and reversibility.

For each lens provide: score 1–10, strongest argument for, strongest argument against, kill risk, unknowns, and conditions to proceed.

## Synthesis
Return:
- decision statement;
- evidence quality;
- weighted score only if weights are explicit;
- disagreements between lenses;
- hard gates from `references/decision-gates.md`;
- verdict: `GO`, `GO IF`, `TEST FIRST`, `NO-GO`, or `INSUFFICIENT EVIDENCE`;
- smallest next action that creates decision-relevant evidence.

Never upgrade an unknown into a positive assumption merely to complete the analysis.
