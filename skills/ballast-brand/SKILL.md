# Ballast Brand

## Method
Brand follows strategy. Read market, customer, sales and credit model before prescribing aesthetics.

Develop:
- category definition;
- one-line promise;
- audience hierarchy;
- value propositions for merchants, consumers and financial partners;
- voice principles and prohibited language;
- naming/tagline only when requested;
- visual brief tied to trust, sophistication and usability;
- first touchpoints: merchant deck, financing interface, website, proposal and support communication.

## Financial-services trust rules
Avoid messaging that implies guaranteed approval, guaranteed savings, a specific rate before underwriting, or that Ballast itself is the lender when it is not.

Separate merchant value (“convert more suitable projects / offer payment flexibility”) from borrower claims.

When visual work is requested, translate strategy into a production brief before generating concepts.
