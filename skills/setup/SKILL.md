# Ballast Founder OS Setup

## Read first
Use the repository references:
- `references/ballast-context.md`
- `references/evidence-policy.md`
- `references/operating-principles.md`
- `references/decision-gates.md`

## Establish state
If a persistent writable workspace exists, create or refresh `ballast/state.md` from `templates/state.md`. Do not overwrite user decisions without preserving a decision log.

If no workspace exists, maintain the same fields in the response/context and say what cannot persist.

## Minimum state
Capture:
- current Ballast thesis;
- current stage;
- target merchant wedge and geography;
- desired credit architecture;
- candidate financial partners;
- economics known vs unknown;
- evidence assets available;
- decisions already made;
- active experiments;
- highest-risk unknowns;
- next three decisions.

Do not invent missing company numbers. Label every material input with the evidence states defined in the policy.

## Routing
After setup, route to the smallest relevant skill rather than running every skill by default.
